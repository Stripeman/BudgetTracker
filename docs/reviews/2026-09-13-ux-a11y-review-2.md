# UX/UI and accessibility review 2 — Bills, Planning, Merchants, pickers (2026-09-13)

Independent, read-only review in headless Edge against the local dev server (fictional data, every write intercepted in the browser), covering the Bills and Planning tabs, the Merchants tab, the quick-entry merchant picker, the theme and category colour pickers and the dashboard notice. 65 screenshots (git-ignored, `.local/review-ui/`).

**Verified sound:** dialog semantics (labelled `role=dialog`, inert background, focus into the first field, Escape back to the opener, in-dialog errors), the merchant combobox (aria-activedescendant, Escape closes the list first, inline creation never submits the expense, duplicate handling), the theme picker (focus to the current option, arrows/Home/End, Escape keeps the account menu open), 320/390px reflow with no horizontal scroll, text contrast across several palettes, non-text contrast of fields, badges and category dots, focus never under the sticky header, colour never the only signal, 28px targets, role awareness for owner/member/viewer, consistent "nothing is deleted" wording.
